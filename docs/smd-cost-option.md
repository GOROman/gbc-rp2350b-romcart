# SMD量産案と部品調達

推奨候補は **RP2354B（QFN-80、内蔵フラッシュ）**。2MiBの内蔵フラッシュは初期32KiB ROMと制御コードに十分。ただし実行中はROMデータをSRAMに置き、外部バスの応答をフラッシュ読み出しに依存させない。RP2350Bは16MiBなど外部フラッシュ容量が必要な用途の候補。

今回完成を進めているキャリアでは Core2350B2 の既存電源・水晶・Flashを使い、モジュールを手実装する。単体SMD版の回路図/基板/ガーバーは未作成。キャリアのガーバーを単体版と呼ばない。

キャリア BOM の LCSC欄は VERIFY。各MPNのJLC実装在庫・代替・rotationは未確認。Core2350B2-KitはPCBAのSMT部品として登録せず手実装。採用する実物とシェル適合を確認してからSMD版を進める。

## 指定コイルを使わない外部DVDD案（一次資料で評価済み）

[RP2350データシート §6.3.7 / Figure24](https://pip.raspberrypi.com/documents/RP-008373-DS-rp2350-datasheet.pdf) は外部1.1V供給を認めています。インダクタを外し、VREG_FB=GND、VREG_LX=NC、VREG_PGND=GND。VREG_VINとVREG_AVDDの3.3V給電はPOR/BORのため維持し、共通4.7µFと各DVDD直近100nFを配置。起動後にVREG.HIZ=1で内部レギュレータを停止します。ソフト停止前も安全な接続として公式に説明されています。

具体的候補は **TLV75801PDRVR（WSON-6）** の可変LDO。例：VIN=3.3V、FB上/下10.0kΩ ±0.1%で `0.55×(1+10k/10k)=1.10V`。入力1µF以上、出力1µF以上（DC bias後0.47µF以上）に、MCUの100nFとbulkを追加。1.1Vの専用型番やJLC在庫を確認していない固定LDOをBOMへ採用したとは扱いません。

[TI一次データシート](https://www.ti.com/lit/ds/symlink/tlv758p.pdf) の500mA容量、出力精度最大1%、WSON RθJA=80.3°C/Wを確認。定格電流だけで採用せず、逆電流・起動過渡・負荷step・温度・出力overshootを評価する必要があります。JLCのこのLDOと抵抗/容量の実装在庫は未確認です。

|構成|コイル欠品|部品/実装|電源効率と条件|判断|
|---|---|---|---|---|
|Core2350B2キャリア|モジュール内蔵電源を利用|手実装モジュール + キャリアPCBA|既存モジュールの動作/電流を測定|現行の試作成果物|
|RP2354B + 内部buck|指定コイルが必要|外部Flash不要、追加LDO不要|小さな損失が期待できるが参照配置必須|低価格量産の第一候補、コイル調達待ち|
|RP2354B + 外部1.1V LDO|指定コイル不要|LDO + FB抵抗2個 + Cを追加|低消費電流なら簡単。大電流では熱と本体電源余裕が問題|条件付き代替候補、未採用|
|RP2354B + 外部buck|別の検証済みコイルまたはモジュール|追加PMIC/コイル/FB/C|効率優先。部品と配置検証が増える|部品最小化の目的では優先度低め|

|DVDD電流|3.3→1.1V LDO損失|WSON温度上昇の概算|5→3.3→1.1V全LDO損失|
|---:|---:|---:|---:|
|20mA|44mW|3.5°C|78mW|

|100mA|220mW|17.7°C|390mW|
|200mA|440mW|35.3°C|780mW|

RθJAはJEDEC条件の概算で実基板温度保証ではありません。200mA/周囲85°CではコアLDOだけでも約120°Cと余裕が小さく、3.3Vレギュレータの発熱も別にあります。本体の5V電源許容電流が不明なまま外部LDOを「安くて確実」と採用しません。

**次の判断**：低コストと電池効率を両立するなら指定コイルの調達/検証を待つ内部buck。納期を優先する外部LDO案は、必要なDVDD電流上限・筐体温度・本体5V予算・JLC部品在庫が確認できた後に単体版へ進めます。今回のモジュール版を単体版へ勝手に置き換えていません。
