# 製造出力

**R0検討用。発注用リリースではありません。** 検証結果は `../validation/RESULTS.md`。

基板案は57.5×52.5mm / 0.8mm / 4層。白 solder mask、表面gold fingersを想定。finger pitch1.5mm、幅1.0mm、長さ5.0mm。厚み・端子位置・鍵形状・面取り・hard gold・ケース高さは実物とJLC能力を照合する必要があります。通常のENIGを耐久hard goldと同等とは扱いません。

外形は実装スペースを確認するための試作矩形で、任天堂/Chromatic純正シェル適合外形の確定版ではありません。挿入深さと端子の左右を実物で確認してください。

BOM.csvは全29部品を1個ずつ記載。Assembly=PCBAは27部品。M1はHAND、J1はPCB。ピックアンドプレースはM1/J1を除外する必要があります。モジュールは2.54mm pin/headerによる手実装で、SMDリフロー対象ではありません。module bottomに部品接触がないこと、pin長さとアダプタFFCの高さを確認。

ガーバー・ドリルは設計ファイルから生成した検討用データです。現在ERC/DRC/未接続/parityはすべて0です。実機・機械適合・全BOM在庫・CPL rotation・CAMレビューが未確認のため発注停止を維持します。端子だけを見て動作するROMカートリッジと判断しないでください。

`BOM-PCBA.csv` は11型番グループ/27実装点のJLC入力補助です。LCSC欄が空なので自動調達確定ではありません。モジュールと接点を除外しています。全体BOMは `BOM.csv`。
